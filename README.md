# 의료 접근성이 건강 결과에 미치는 영향 분석

BRFSS 2015 당뇨병 건강지표 데이터셋(25만 행)을 이용해 **의료 접근성(보험 유무, 비용 부담으로 인한 병원 미방문, 정기검진 여부)이 만성질환·건강 결과와 어떤 관계가 있는지** 분석한 프로젝트입니다. EDA, 교차분석, 로지스틱 회귀(오즈비 추정), 모델 가정 점검, 예측 모델링까지 전체 데이터 분석 파이프라인을 다룹니다.

## 문제 정의

- **발견하고 싶은 문제**: 의료 접근성이 낮은 집단(비용 부담으로 병원을 못 간 경험, 보험 미보유)이 실제로 만성질환 관리와 건강 결과에서 더 취약한가? 소득·연령 같은 교란요인을 통제해도 접근성 자체의 독립적 영향이 남는가?
- **이유**: 의료 접근성 격차가 건강 결과에 실질적 영향을 미치는지 데이터로 검증하면, 어떤 소득·연령대에 접근성 개선 정책이 우선적으로 필요한지 근거를 제시할 수 있습니다.

## 분석 파이프라인

`notebooks/1.0-healthcare-access-analysis.ipynb`

1. **데이터 이해** — 데이터를 고른 이유, 행/컬럼/기간의 의미, 출처·저작권, 데이터 자체의 한계와 편향
2. **데이터 전처리** — 결측치/중복행/값 범위 점검, `BMI` 이상치(IQR) 점검, 처리 방침 명시
3. **EDA** — 3.1 타깃 변수(`Diabetes_binary`) 분포와 클래스 불균형, 3.2 접근성 변수(`AnyHealthcare`, `NoDocbcCost`, `CholCheck`) 분포
4. **교차분석 & 카이제곱검정** — 접근성 변수별 건강 결과 비율 차이
5. **교란변수 선정** — 후보 변수를 접근성·결과지표 양쪽과의 상관관계로 스크리닝(히트맵·산점도), 매개변수 가능성까지 논리적으로 재검토해 핵심 교란변수 확정
6. **소득 심층 층화분석** — 소득 구간별 접근성·결과지표 변화, 스피어만 상관
7. **로지스틱 회귀(오즈비)** — 모델 선택 근거 명시, 비보정 vs 보정(소득·연령·성별·교육·BMI 통제) 모델 비교
   - 7.1 모델 가정 점검 — 다중공선성(VIF), 선형성(Box-Tidwell 검정), BMI 구간화 모델과의 오즈비 비교로 비선형성이 결론에 영향을 주는지 검증
   - 7.2 민감도 분석 — `CholCheck` 제외 시 나머지 접근성 변수 오즈비 변화로 검출편향 의심을 검증
   - 7.3 보조 결과지표(`PoorGenHlth`, 주관적 건강상태) 모델
8. **예측 모델링 및 성능 평가** — 평가지표 선택 근거 명시, 기준선(`DummyClassifier`) vs 접근성 변수만 사용한 모델 vs 전체 21개 변수 모델 비교, 5-fold 교차검증으로 결과 재확인 (Train/Test split, ROC-AUC, 분류 리포트, 혼동행렬)
   - 8.1 변수 중요도 — 표준화 계수로 Full 모델이 실제로 어떤 변수에 의존하는지 확인
   - 8.2 트리 기반 모델과의 비교 — `HistGradientBoostingClassifier`로 같은 조건에서 학습해, 해석 가능성을 택한 대가로 포기한 예측 성능이 얼마인지와 접근성 변수의 예측력 부재가 모델 선택 탓인지 검증
9. **합성데이터 검증** — 진짜 효과 크기를 아는 가상 데이터로 (1) 교란변수 통제가 추정치를 진짜 값에 수렴시키는지, (2) 검진율 차이만으로 검출편향이 오즈비를 부풀리는지 직접 시뮬레이션으로 증명
10. **종합 결론, 한계, 비즈니스 인사이트** — 접근성 지표별 판정(무엇이 실제 신호이고 무엇이 검출편향인지), 데이터·분석 양쪽의 한계 구분, 시장 기회·제품 실현 가능성·피해야 할 기획·KPI 설계 리스크

## 핵심 결과

- 교란변수는 "조정 후 오즈비가 얼마나 바뀌는가"가 아니라 접근성·결과 양쪽과의 상관관계로 사전 스크리닝했습니다. `Income`·`Age`·`Education`·`Sex`는 두 조건을 모두 만족하는 교란변수인 반면, `BMI`는 결과와는 강하게 연관되지만(r=0.217) 접근성과는 거의 무관해(r≈0.02~0.06) 매개변수 가능성이 있는 별도 위험요인으로 구분했습니다.
- `NoDocbcCost`(비용 부담으로 병원 미방문 경험)는 소득·연령 등을 통제한 뒤에도 당뇨(OR 1.37)와 주관적 건강불량(OR 2.46)에 독립적으로 유의한 영향을 미칩니다.
- `CholCheck`, `AnyHealthcare`의 큰 오즈비(각 5.10배, 1.23배)는 인과효과보다 **검출편향**(검진·의료 이용이 있어야 진단이 기록되는 구조)으로 해석해야 합니다. 실제로 `CholCheck`를 모델에서 빼는 민감도 분석을 해보면, `NoDocbcCost`는 거의 그대로지만 `AnyHealthcare`는 오히려 오즈비가 더 커집니다(1.23→1.33) — `CholCheck`와 상관이 있던(r=0.118) 검출편향이 `AnyHealthcare` 쪽으로 옮겨간 것으로, 변수를 빼는 게 편향의 해결책이 아님을 보여줍니다.
- 소득 최하위군은 최상위군 대비 비용장벽 7배, 주관적 건강불량 7.7배, 당뇨 유병률 3배 높은 뚜렷한 사회경제적 구배를 보입니다.
- 접근성 변수 3개만으로 만든 예측 모델은 ROC-AUC 0.532(사실상 무작위 수준)에 그치지만, 전체 21개 변수를 쓴 모델은 0.822까지 올라갑니다 — **통계적으로 유의한 연관과 예측력은 별개**임을 보여줍니다.
- 같은 변수를 트리 기반 부스팅(`HistGradientBoostingClassifier`)으로 학습하면 ROC-AUC가 0.822→0.830으로 소폭 오르는 데 그치고, 접근성 변수 3개만 쓴 경우에는 부스팅 트리도 0.5317로 로지스틱 회귀(0.5317)와 동일합니다 — 해석 가능성을 위해 로지스틱 회귀를 택하며 포기한 예측 성능은 크지 않고, 접근성 변수의 예측력 부재도 모델 선택이 아니라 데이터 자체의 성질임을 확인했습니다.
- 항상 "당뇨 아님"으로만 예측하는 기준선(baseline)은 정확도 86.1%지만 재현율은 0%입니다. Full 예측 모델(ROC-AUC 0.822, 재현율 76%)만이 이 기준선을 실질적으로 능가했습니다 — 불균형 데이터에서 정확도만으로 모델을 평가하면 안 되는 이유를 보여주는 사례입니다.
- 진짜 오즈비를 아는 합성데이터 실험에서, 교란변수를 통제하니 추정치(2.14→1.29)가 실제 설계값(1.3)에 정확히 수렴했고, 검진 여부가 결과와 완전히 무관하게 설계됐음에도 발견 확률 차이만으로 오즈비가 1.02→2.69로 부풀려졌습니다 — 이 분석에서 쓴 통계적 논리(교란변수 통제, 검출편향 해석)가 실제로 타당함을 뒷받침합니다.

## 한계

- 설문 가중치(survey weight)가 없어 전국 대표성을 보정할 수 없고, 인종/민족 변수가 없어 소득 외의 격차는 분석할 수 없습니다.
- 진단 여부·생활습관·체중/키까지 전부 자가보고(self-report)라 사회적 바람직성 편향이 있을 수 있고, 지리 정보가 없어 지역별 격차도 볼 수 없습니다. 데이터도 2015년(오바마케어 시행 초기) 시점입니다.
- `Diabetes_binary`는 실제 유병 여부가 아니라 "진단받은 적 있는지"를 묻는 자가보고 변수라 미진단 편향 가능성이 있습니다.
- 단면(cross-sectional) 데이터이므로 오즈비는 연관성이지 인과관계를 증명하지 않습니다.
- 전체 표본의 9.5%가 완전 중복행이지만, 구간화된 범주형 변수 특성상 데이터 오류로 보기 어려워 삭제하지 않고 유지했습니다.
