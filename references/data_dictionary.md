# 데이터 설명서 (Data Dictionary)

**파일**: `data/raw/diabetes_binary_health_indicators_BRFSS2015.csv`
**출처**: CDC BRFSS(Behavioral Risk Factor Surveillance System) 2015 설문조사를 기반으로 가공된 공개 파생 데이터셋
**규모**: 253,680행 × 22열, 결측치 없음
**단위**: 모든 컬럼이 `float64`로 저장돼 있지만 실제로는 이진(0/1) 또는 순서형 구간 코드다.

## 컬럼 사전

| 컬럼명 | 타입 | 값 범위 / 코드 | 설명 |
|---|---|---|---|
| `Diabetes_binary` | 이진 | 0 = 없음, 1 = 있음 | 당뇨 진단 여부 (**타깃 변수**, 자가보고) |
| `HighBP` | 이진 | 0/1 | 고혈압 진단 여부 |
| `HighChol` | 이진 | 0/1 | 고콜레스테롤 진단 여부 |
| `CholCheck` | 이진 | 0/1 | 최근 5년 내 콜레스테롤 검사 여부 (접근성 변수) |
| `BMI` | 연속 | 대략 12~98 | 체질량지수 (자가보고 키·몸무게 기반) |
| `Smoker` | 이진 | 0/1 | 평생 담배 100개비 이상 흡연 여부 (현재 흡연 여부 아님) |
| `Stroke` | 이진 | 0/1 | 뇌졸중 진단 여부 |
| `HeartDiseaseorAttack` | 이진 | 0/1 | 관상동맥질환 또는 심근경색 진단 여부 |
| `PhysActivity` | 이진 | 0/1 | 최근 30일 내 (직업 외) 신체활동 여부 |
| `Fruits` | 이진 | 0/1 | 하루 1회 이상 과일 섭취 여부 |
| `Veggies` | 이진 | 0/1 | 하루 1회 이상 채소 섭취 여부 |
| `HvyAlcoholConsump` | 이진 | 0/1 | 과음 여부 (성인 남성 주 14잔 초과 / 여성 주 7잔 초과) |
| `AnyHealthcare` | 이진 | 0/1 | 건강보험 등 의료 이용 수단 보유 여부 (접근성 변수) |
| `NoDocbcCost` | 이진 | 0/1 | 최근 12개월 내 비용 때문에 병원에 못 간 경험 (접근성 변수) |
| `GenHlth` | 순서형 | 1~5 | 주관적 건강상태 (1=Excellent … 5=Poor) |
| `MentHlth` | 이산 | 0~30 | 최근 30일 중 정신건강이 안 좋았던 날수 |
| `PhysHlth` | 이산 | 0~30 | 최근 30일 중 신체건강이 안 좋았던 날수 |
| `DiffWalk` | 이진 | 0/1 | 걷기·계단 오르기에 심각한 어려움이 있는지 |
| `Sex` | 이진 | 0 = 여성, 1 = 남성 | 성별 |
| `Age` | 순서형 | 1~13 | 5세 단위 연령 구간 (아래 매핑 참고) |
| `Education` | 순서형 | 1~6 | 최종 학력 (아래 매핑 참고) |
| `Income` | 순서형 | 1~8 | 가구 연소득 구간 (아래 매핑 참고) |

## 분석에서 파생시킨 변수 (원본에는 없음)

`notebooks/1.0-healthcare-access-analysis.ipynb`에서 만든 파생 컬럼:

- `AgeGroup`, `IncomeGroup`, `GenHlthLabel` — 위 코드 매핑을 문자열 라벨로 바꾼 컬럼 (시각화용)
- `PoorGenHlth` — `GenHlth >= 4`(Fair/Poor)를 1로 묶은 이진 결과지표

## 알려진 한계

- 설문 가중치(survey weight) 컬럼이 원본에서 빠져 있어, 전국 대표성을 엄밀히 보장하지 않는다.
- 인종/민족 변수가 없다.
- `Diabetes_binary`는 실제 유병 여부가 아니라 "진단받은 적 있는지"를 묻는 자가보고 변수다.
- 전체 행의 9.5%가 완전 중복행이지만, 구간화된 범주형 변수 특성상 데이터 오류로 보기 어려워 삭제하지 않았다.
